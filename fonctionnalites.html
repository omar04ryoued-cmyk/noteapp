Éditeur

Prise de notes en Markdown, avec aperçu en direct

Rédigez en Markdown et voyez le rendu se mettre à jour instantanément : titres, listes, code coloré, tableaux.

  • Gras, italique, souligné, couleur de texte
  • Coloration syntaxique automatique du code
  • Liens internes entre vos notes avec [[Titre]]
  • Import de PDF et vidéos en pièce jointe

Mémorisation

Des flashcards qui savent quand vous réviser

Un algorithme de répétition espacée (inspiré d'Anki) programme chaque carte au moment idéal pour la mémoire long terme.

  • Intervalles de révision qui s'allongent automatiquement
  • Notation en 4 niveaux : Encore / Difficile / Bien / Facile
  • Suivi de progression : nouvelles, en cours, maîtrisées

  • Historique de versions restaurable
  • Export/Import complet de vos données en JSON
